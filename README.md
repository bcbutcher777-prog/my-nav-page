# my-nav-page

一个基于 Vue 打包生成的静态导航首页，适合直接部署到 GitHub Pages 或其他静态托管环境。

## 功能

- 实时时钟与日期展示
- 定位天气展示
- 百度搜索框
- 常用网站快捷入口
- PWA 支持，包含离线缓存

## 在线/本地预览

这个项目已经是构建后的静态文件，可以直接通过静态服务器打开 `index.html`。

例如：

- 使用任意本地静态服务器
- 直接部署到 GitHub Pages

## 项目结构

- `index.html`：页面入口
- `css/`：样式文件
- `js/`：脚本文件
- `img/`：图标资源
- `service-worker.js`：离线缓存逻辑
- `manifest.json`：PWA 配置

## 说明

- 页面搜索默认跳转到百度
- 天气功能依赖外部接口
- 适合做个人导航页、常用站点入口页
